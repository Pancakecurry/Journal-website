# Campus Atelier Journal

Campus Atelier Journal is the working codename for a private, playful, local-friendly journaling environment organized around **the Day**. It is intended to make recording ordinary life feel like placing thoughts, photographs, moods, reflections, and memories into a beautifully maintained personal notebook. The public product name is not final.

## Project status

**Current phase:** Task 000 — Product definition

This repository currently contains product and UX source-of-truth documentation only. No application framework, production UI, persistence layer, or technology stack has been selected or scaffolded. There are intentionally no installation or run instructions yet.

Future contributors and coding agents must read [AGENTS.md](AGENTS.md) before making changes.
